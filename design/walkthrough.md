# html2text 实现总结

我们成功地从零开始，使用纯 TypeScript 实现了一个功能完整的 HTML 到 Markdown 转换器。

## 核心功能演示

### 1. 转换管线
- **输入**: 原始 HTML 字符串。
- **阶段一**: 解析为 `HtmlNode[]` AST。
- **阶段二**: 转换为 `MdNode[]` AST。
- **阶段三**: 序列化为 Markdown 字符串。

### 2. 特色支持
- **YAML Front Matter**:
  ```markdown
  ---
  title: ...
  ---
  ```
- **美观的表格**: 自动计算并填充空格以对齐列。
- **嵌套结构**: 支持多级列表和复杂的行内格式嵌套。
- **代码块**: 提取 CSS 类名作为语言标识符（如 `language-typescript`）。

## 实现细节
- **解析器 (`parser.ts`)**: 使用游标遍历字符串，手动处理属性提取，解决了单双引号、无引号属性的解析。
- **生成器 (`stringify.ts`)**: 实现了智能的块间距管理，确保标题、段落和列表之间有正确的空行。
- **类型系统 (`types.ts`)**: 基于判别并集 (Discriminated Unions) 构建，提供了极佳的开发体验。

## 如何运行
在 `html2text` 目录下执行：
```bash
npx ts-node test-run.ts
```

## 下一步建议
- **转义增强**: 目前对 Markdown 特殊字符（如 `_`, `*`）的转义是基础级别的，对于非常复杂的文本内容可以进一步增强。
- **HTML 容错**: 手写解析器在处理严重畸形（标签交叉嵌套）的 HTML 时可能有限制，可以通过增加更多的栈校验逻辑来优化。
